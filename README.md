# Credit Default Prediction

Help a Taiwan-based card issuer predict default and understand its key drivers, to guide approvals and credit limits.

## Approach

- Exploratory analysis of customer and repayment features
- Logistic Regression, Random Forest, AdaBoost, XGBoost and LightGBM

## Results

Accuracy between about 0.78 and 0.82 and ROC-AUC between about 0.71 and 0.89 in the saved notebook output.
